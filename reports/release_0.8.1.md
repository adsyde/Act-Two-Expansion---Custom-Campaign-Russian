# Релиз 0.8.1

Дата: 2026-10-01. Ветка подготовки: `update/upstream-0.8.1`.

## Источник и изменения

- Оригинал установлен BG3MM из Nexus, мод 24689, файл 131624, версия 0.8.1.
- Установленный пакет скопирован без изменений; SHA256 записан в `upstream_0.8.1.md`.
- Найден один XML локализации, 5092 строки.
- Добавлены 99 строк, изменены тексты 35 строк, только версии обновлены у 146 строк.
- Переведены все 134 строки очереди в трёх батчах `batch_081_*.jsonl`.
- В памяти 4879 утверждённых переводов; 213 пустых или технических строк исключены.
- Названия Menacing Attack, Shocking Grasp, Worg, Blink Dog и Necromite сверены
  по совпадающим contentuid английской и русской локализации игры.

## Проверки и упаковка

- QA: 0 блокирующих ошибок. Три неблокирующих предупреждения: технический идентификатор WORG сохранён
  по правилам проекта, а два прежних предупреждения касаются о переводе текстовых
  пометок `<WIP...>`; это не игровые теги.
- Русский XML перечитан; все 4879 contentuid и version совпадают с оригиналом.
- XML успешно скомпилирован для проверки. В пакет включены только русский XML
  в собственной папке модуля и `meta.lsx`; `.loca` в пакете отсутствует.
- UUID перевода сохранён, автор `adsyde`, зависимость оригинала использует
  Version64 `36028797018964347` из его ModuleInfo.
- ZIP содержит пакет перевода и `УСТАНОВКА.txt`; целостность архива проверена.
- Новая версия в живой игре и QuickStart 0.8.1 пока не проверялись.

Для установки нужно заменить прежний пакет перевода, включить перевод после
оригинала и выбрать русский язык игры.
