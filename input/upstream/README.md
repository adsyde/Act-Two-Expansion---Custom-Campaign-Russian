# input/upstream — оригинальные файлы мода (READ-ONLY)

Сюда кладется `.pak` мода Act Two Expansion, скачанный с Nexus.

Содержимое каталога **не попадает в git** (кроме этого файла): это чужой
контент объемом в сотни мегабайт. Каждый, кто работает с репозиторием,
скачивает `.pak` сам.

После того как файл положен сюда, укажите его в `config/tools.json`:

```json
"upstream": {
  "version": "0.8",
  "pak": "input/upstream/ActTwoExpansion_<uuid>.pak",
  ...
}
```

Менять файлы в этом каталоге запрещено. SHA256 распакованного
`.pak` фиксируется в `reports/upstream_<версия>.md` — по нему видно, ту ли
сборку мода переводили.
